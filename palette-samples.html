rusti palette samples

Fifteen options for the two colours you asked about, each shown on one frame of the real TUI: your query marker, a running tool, ok / fail, the ℹ permission line, a diff hunk, inline code, the picker's selected row, the working hint, the input prompt and the footer. Swatches under each card carry the exact codes, so whichever you pick I can apply it directly. #1 is what ships today; #2 is what I recommended.

New in this pass: each card now also shows the two things rusti does not do yet — a rendered table (aligned columns and a rule, instead of raw | pipes |) and syntax highlighting in a fenced block (keys, strings, numbers and booleans coloured by role, instead of one flat tan). The token colours are derived from each palette rather than invented: key = the palette's own accent, string = its ok colour, number = its code colour, boolean = its info colour, punctuation = its grey. So picking a theme picks the highlighting too.
