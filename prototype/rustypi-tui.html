rustypi --tui  ·  D:\Code\AI\Agents\rustypi  · 
prototype — mock agent, no LLM, no files touched. Click the page once, then just type.
three voices — you are a cyan › after the message number · reasoning is dim italic behind a gutter bar · the answer is the brightest text, marked ⏺. every voice keeps its marker down each wrapped row, so no line can be read as the wrong voice.
tasks — type anything · every turn opens with a reasoning block · include the word ask for an ask_user turn · fail for a failing tool
slash — press / for the command menu (5 rows, up/down for the rest, Tab completes, Enter runs, Esc dismisses)
quit — /quit or Ctrl+C twice to close
timing — each finished tool line carries its own wall time · the turn total is the · tok · tps · s line
keys — Enter submit · Esc interrupt · Ctrl+C clears input, twice quits · Ctrl+D quits when empty · up/down history · PgUp/PgDn scroll
sessions — /resume opens the session picker (arrows, Enter resumes) · /resume 2 or /resume tui-colors skips it · /rename <name> renames the active one (shown in the title bar)
extra — type --tree for the session-tree browser screen (the CLI --tree flag)
